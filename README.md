# Οικοδομικές Εργασίες — εταιρικός ιστότοπος

Στατικός, responsive ιστότοπος στα Ελληνικά για επιχείρηση οικοδομικών εργασιών και ανακαινίσεων.

## Περιεχόμενα
- Αρχική σελίδα, υπηρεσίες, portfolio και επικοινωνία
- Προσχέδια Πολιτικής Απορρήτου, Όρων Χρήσης και Πολιτικής Cookies
- Βασικό SEO: περιγραφές σελίδων, canonical placeholders, Open Graph, JSON-LD, sitemap και robots.txt
- Απλός μηχανισμός προτίμησης cookies
- Φόρμα επικοινωνίας που συντάσσει email μέσω του προγράμματος email του επισκέπτη (δεν υπάρχει backend)

## Τοπική προεπισκόπηση
Άνοιγμα του `index.html` σε browser ή εκτέλεση ενός απλού static server από τη ρίζα του project.

## Υποχρεωτικά πριν από δημοσίευση
1. Αντικαταστήστε όλα τα `[placeholders]` με ακριβή, πραγματικά στοιχεία επιχείρησης.
2. Αντικαταστήστε το `YOUR-DOMAIN.example` σε canonical, sitemap και robots.txt.
3. Ορίστε το πραγματικό email στο `assets/js/main.js` και στα στοιχεία επικοινωνίας.
4. Ελέγξτε ότι οι υπηρεσίες, οι φωτογραφίες, τα έργα και οι ισχυρισμοί ανταποκρίνονται στην πραγματικότητα.
5. Εξατομικεύστε τα νομικά κείμενα με βάση τις πραγματικές ροές δεδομένων, τους παρόχους φιλοξενίας, τα analytics, τα cookies και τις συμβάσεις. Ζητήστε έλεγχο από νομικό σύμβουλο.
6. Η τρέχουσα φόρμα δεν αποστέλλει δεδομένα σε server. Για κανονική φόρμα απαιτείται ασφαλής backend υπηρεσία, προστασία spam και κατάλληλη ενημέρωση απορρήτου.
7. Η τρέχουσα υλοποίηση δεν φορτώνει analytics ή marketing scripts. Αν προστεθούν, απαιτείται κατάλληλος μηχανισμός συγκατάθεσης πριν από οποιαδήποτε ενεργοποίηση.

## Δημοσίευση μέσω GitHub Pages
Στο GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Μετά την ενεργοποίηση, ρυθμίστε το domain και ενημερώστε τα SEO αρχεία.

## Σημείωση
Το repository περιέχει αρχικό λειτουργικό frontend και νομικά προσχέδια, όχι πιστοποίηση συμμόρφωσης ή εξατομικευμένη νομική γνωμοδότηση.
